# Razvoj softvera II — testovi

Testovi u istom izgledu i načinu rada kao [RS1 teorija](https://github.com/imadali120/rs1teorija).

**[Otvori testove](https://imadali120.github.io/rs2teorija/)**

99 pitanja s ClassMarkera podijeljeno je u pet stalnih testova: 20 + 20 + 20 + 20 + 19 pitanja. Dostupni su vježbanje s objašnjenjima, simulacija ispita, nasumični redoslijed i pregled pogrešnih odgovora.

Može se izabrati izvorni ClassMarker ključ ili provjereni/precizirani ključ. Objašnjenja navode greške i zastarjele tvrdnje izvornog testa, uz kontekst dostavljenih RSII lekcija i linkove na dokumentaciju za sporne stavke.

GitHub Pages objavljuje sadržaj iz korijena `main` grane, isto kao RS1. Za lokalno korištenje dovoljno je otvoriti `index.html`; slike se nalaze u folderu `assets`.
