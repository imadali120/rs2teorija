# Razvoj softvera II — testovi

Testovi u istom izgledu i načinu rada kao [RS1 teorija](https://github.com/imadali120/rs1teorija).

**[Otvori testove](https://imadali120.github.io/rs2teorija/)**

107 pitanja (99 iz ClassMarkera i 8 dodatnih iz fotografija / spiska ispitnih pitanja) podijeljeno je po oblastima:

- HTTP metode i zaglavlja: 19 pitanja
- HTTP statusni kodovi: 24 pitanja
- Web API, rutiranje i sigurnost: 26 pitanja
- DevOps: 8 pitanja
- Docker: 14 pitanja
- Mobilni razvoj — Shared i PCL: 3 pitanja
- Sistemi preporuke: 13 pitanja
 Dostupni su vježbanje s objašnjenjima, simulacija ispita, nasumični redoslijed i pregled pogrešnih odgovora.

Može se izabrati izvorni ClassMarker ključ ili provjereni/precizirani ključ. Objašnjenja navode greške i zastarjele tvrdnje izvornog testa, uz kontekst dostavljenih RSII lekcija i linkove na dokumentaciju za sporne stavke.

GitHub Pages objavljuje sadržaj iz korijena `main` grane, isto kao RS1. Za lokalno korištenje dovoljno je otvoriti `index.html`; slike se nalaze u folderu `assets`.

Oznaka **Ispitno pitanje** prikazuje se ispod označenog pitanja. Za fotografije i spisak po sjećanju izvor oznake naveden je u objašnjenju. Ponuđeni odgovori za pitanja zapamćena samo okvirno su rekonstrukcija za vježbanje, ne potvrđen prijepis ispita. Nije poznat izvorni ocjenjivački ključ fotografisanih pitanja; odgovori su izvedeni iz gradiva i dokumentacije.
